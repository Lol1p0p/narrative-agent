Narrative Agent
启用后，消息发送将经过多Agent流水线（规划 → 工具执行 → 写作 → 合并分析）处理。

预设处理模式

选择如何处理酒馆预设中的提示词。分割注入模式会将系统提示注入规划Agent、用户提示注入写作Agent。

世界书来源

选择世界书条目的加载来源。卡包内嵌模式适用于已通过 narrative-agent-worldbook skill 规范化并嵌入卡包的世界书。

并行处理

开启后，不依赖合并分析结果的 post_pipeline 工具将与分析 Agent 并行调用，可缩短 Pipeline 整体耗时约 30-40%。依赖 story_summary / state_summary / known_context 的工具仍会在合并分析之后串行执行。
